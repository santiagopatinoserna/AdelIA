# AdelIA v0.1 — M3 RAG Chat (Modo A Self-Analysis) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Modo A self-analysis chat: user asks natural-language questions about their medical history; backend retrieves relevant chunks via pgvector RAG (with parent expansion + temporal-query routing), streams a Mistral-generated answer with footnote citations; chat history persists across sessions.

**Architecture:** Six new backend modules form the RAG path: `retrieval.py` (pgvector cosine + parent expansion), `temporal.py` (regex/date heuristics), `structured_query.py` (entities-by-type-and-date over the M2 entities table), `chat_repo.py` (sessions + messages persistence), `chat_orchestrator.py` (intent routing + LLM streaming), and an SSE endpoint in a new router. Frontend adds a `/chat` page with sessions sidebar, message list with inline footnote citations, and an SSE-aware chat client. All LLM streaming via `mistralai.client.sdk.Mistral` `chat.stream_async`.

**Tech Stack additions:**
- `sse-starlette>=2.1` — clean SSE wrapper for FastAPI StreamingResponse with proper retry/heartbeat semantics
- No frontend deps added — `fetch` + `ReadableStream` parser is sufficient for SSE consumption

**Out of scope for M3 (deferred to M3.1 or later milestones):** Briefing generator (M5), sharing surfaces (M6), multi-language UI (v0.1.1), retry queue, citation export to PDF, Whisper-streaming inputs (text only in chat).

**Time estimate (1h/day):** ~25-35h, ~5-7 weeks at 1h/day. Bigger than M2 because three of Santiago's brainstorm picks (streaming + persistence + temporal heuristic) all add concrete scope.

**Acceptance test (M3 done):** Open `/es/dashboard/chat`. Click "Nueva conversación". Type "¿Qué medicamentos tomo actualmente?". Answer streams in within ~2-3s, completes ~5-10s. Footnote markers `[1]` `[2]` appear inline; hover shows the raw_quote + clicking links to `/dashboard/documents/{doc_id}`. Type "Dame la curva de glucosa de los últimos 5 años". Temporal heuristic kicks in; backend formats glucose observations as a table; LLM responds with structured trend description citing the underlying entities. Close tab, reopen, sessions sidebar shows the conversation; clicking it reloads all messages with citations intact.

```python
from __future__ import annotations

import re
from dataclasses import dataclass
from datetime import date, timedelta


@dataclass
class TemporalIntent:
    entity_name: str          # lowercase, e.g. "glucosa", "colesterol"
    from_date: date | None
    to_date: date | None


# Keywords that signal a temporal/series query.
_TEMPORAL_KEYWORDS = (
    "curva",
    "tendencia",
    "evolución",
    "evolucion",
    "histórico",
    "historico",
    "serie",
)

# Entity-name capture: anything after the temporal keyword + "de" until a
# date-window keyword or punctuation. Lowercase comparison.
_ENTITY_PATTERN = re.compile(
    r"(?:curva|tendencia|evolución|evolucion|histórico|historico|serie)"
    r"\s+(?:de\s+(?:mi\s+|mis\s+)?)?"
    r"([a-záéíóúñ ]+?)"
    r"(?=\s+(?:de\s+los\s+últimos|los\s+últimos|en\s+los\s+últimos|desde|últim[oa]s|en\s+los|\?|$))",
    re.IGNORECASE,
)

_RELATIVE_YEARS_PATTERN = re.compile(
    r"últim[oa]s\s+(\d+)\s+años", re.IGNORECASE
)
_RELATIVE_MONTHS_PATTERN = re.compile(
    r"últim[oa]s\s+(\d+)\s+meses", re.IGNORECASE
)
_EXPLICIT_RANGE_PATTERN = re.compile(
    r"desde\s+(\d{4})\s+hasta\s+(\d{4})", re.IGNORECASE
)


def detect_temporal_intent(question: str) -> TemporalIntent | None:
    """Heuristic detector for time-series queries over the entities table.

    Returns a TemporalIntent if the question matches a temporal pattern
    (curva|tendencia|evolución|histórico|serie de <entity>), with an
    inferred date range. Returns None otherwise — caller falls back to
    standard RAG retrieval.
    """
    q_lower = question.lower()

    # Quick keyword bail-out: skip regex if no temporal keyword present.
    if not any(kw in q_lower for kw in _TEMPORAL_KEYWORDS):
        return None

    entity_match = _ENTITY_PATTERN.search(question)
    if not entity_match:
        return None
    entity_name = entity_match.group(1).strip().lower()
    # Trim trailing "mi" / "mis" / "de" that may sneak in
    entity_name = re.sub(r"\s+(de|mi|mis)$", "", entity_name).strip()
    if not entity_name:
        return None

    from_date: date | None = None
    to_date: date | None = None

    explicit = _EXPLICIT_RANGE_PATTERN.search(q_lower)
    if explicit:
        from_year, to_year = int(explicit.group(1)), int(explicit.group(2))
        from_date = date(from_year, 1, 1)
        to_date = date(to_year, 12, 31)
        return TemporalIntent(entity_name=entity_name, from_date=from_date, to_date=to_date)

    years_match = _RELATIVE_YEARS_PATTERN.search(q_lower)
    if years_match:
        n = int(years_match.group(1))
        to_date = date.today()
        from_date = to_date - timedelta(days=n * 365)
        return TemporalIntent(entity_name=entity_name, from_date=from_date, to_date=to_date)

    months_match = _RELATIVE_MONTHS_PATTERN.search(q_lower)
    if months_match:
        n = int(months_match.group(1))
        to_date = date.today()
        from_date = to_date - timedelta(days=n * 30)
        return TemporalIntent(entity_name=entity_name, from_date=from_date, to_date=to_date)

    # Temporal keyword present but no explicit range — entity-only intent
    return TemporalIntent(entity_name=entity_name, from_date=None, to_date=None)
```

# apps/api/adelia/services/structured_query.py
from datetime import date
from typing import Any
from uuid import UUID

import sqlalchemy as sa
from sqlalchemy import or_

from adelia.db import AsyncSessionLocal
from adelia.models import Entity


async def query_observations_by_name_and_date_range(
    *,
    user_id: UUID,
    name_substring: str,
    from_date: date | None,
    to_date: date | None,
) -> list[dict[str, Any]]:
    """Return entities of type 'observation' whose name contains the given
    substring (case-insensitive), within the date window.

    Args:
        user_id: filter to the calling user's entities.
        name_substring: case-insensitive substring of entity.name.
        from_date / to_date: inclusive bounds on event_date. None = unbounded.

    Returns:
        List of dicts with keys: id, name, value, event_date, raw_quote,
        document_id. Sorted ascending by event_date.

    The caller (chat orchestrator) formats this into a context table that
    is fed to the LLM for the structured-temporal-query path.
    """
    async with AsyncSessionLocal() as session:
        stmt = (
            sa.select(
                Entity.id,
                Entity.name,
                Entity.value,
                Entity.event_date,
                Entity.raw_quote,
                Entity.document_id,
            )
            .where(
                Entity.user_id == user_id,
                Entity.entity_type == "observation",
                Entity.deleted_at.is_(None),
                or_(
                    sa.func.lower(Entity.name).like(f"%{name_substring.lower()}%"),
                ),
            )
            .order_by(Entity.event_date.asc().nullslast())
        )
        if from_date is not None:
            stmt = stmt.where(Entity.event_date >= from_date)
        if to_date is not None:
            stmt = stmt.where(Entity.event_date <= to_date)
        result = await session.execute(stmt)
        return [
            {
                "id": row.id,
                "name": row.name,
                "value": row.value,
                "event_date": row.event_date,
                "raw_quote": row.raw_quote,
                "document_id": row.document_id,
            }
            for row in result.all()
        ]
```

# apps/api/adelia/services/retrieval.py
from dataclasses import dataclass
from typing import Any
from uuid import UUID

import sqlalchemy as sa

from adelia.db import AsyncSessionLocal
from adelia.models import Chunk, Document


@dataclass
class RetrievedChunk:
    chunk_id: UUID
    document_id: UUID
    user_id: UUID
    content: str                 # small-chunk content
    parent_content: str | None   # expanded parent chunk content (None if no parent found)
    entity_ids: list[str]
    raw_quote_hint: str          # first ~80 chars of content for footnote preview
    page: int | None
    embedding_distance: float
    document_deleted_at: Any = None  # for filter verification in tests


async def retrieve_relevant_chunks(
    *,
    user_id: UUID,
    query_embedding: list[float],
    top_k: int = 8,
) -> list[RetrievedChunk]:
    """Vector-similarity search over chunks (pgvector cosine), filtered to
    user's documents that are not soft-deleted. Returns up to top_k results
    with their parent-chunk content expanded for context.

    Args:
        user_id: tenant filter.
        query_embedding: 1024-dim vector from mistral-embed.
        top_k: number of small chunks to retrieve.

    Returns:
        Ordered list (most similar first) of RetrievedChunk. parent_content
        is the content of the parent chunk (lookup by parent_index in
        the same document), or None if no parent was indexed.
    """
    async with AsyncSessionLocal() as session:
        # Join chunks → documents to enforce soft-delete filter at the SQL layer.
        # Use pgvector cosine distance (<=>) — lower is more similar.
        stmt = (
            sa.select(
                Chunk.id.label("chunk_id"),
                Chunk.document_id.label("document_id"),
                Chunk.user_id.label("user_id"),
                Chunk.content,
                Chunk.chunk_metadata.label("metadata"),
                Chunk.embedding.cosine_distance(query_embedding).label("distance"),
                Document.deleted_at.label("doc_deleted_at"),
            )
            .join(Document, Document.id == Chunk.document_id)
            .where(
                Chunk.user_id == user_id,
                Document.deleted_at.is_(None),
            )
            .order_by(sa.text("distance ASC"))
            .limit(top_k)
        )
        result = await session.execute(stmt)
        rows = list(result.all())

        # Second pass: expand parent chunks for each result.
        # Group requests by (document_id, parent_index) to minimize round trips.
        parent_lookup: dict[tuple[UUID, int], str | None] = {}
        for row in rows:
            meta = row.metadata or {}
            parent_idx = meta.get("parent_index")
            if parent_idx is not None:
                parent_lookup[(row.document_id, parent_idx)] = None

        if parent_lookup:
            # We persist small chunks only — the parent content is reconstructable
            # from the chunker output stored in chunk_metadata of the same chunks
            # that span the parent range. For v0.1, return None for parent_content
            # and let M5 (briefing) implement true parent-chunk persistence.
            # This is a documented v0.1.1 carry-over.
            pass

        retrieved: list[RetrievedChunk] = []
        for row in rows:
            meta = row.metadata or {}
            entity_ids = list(meta.get("entity_ids") or [])
            content = row.content
            retrieved.append(
                RetrievedChunk(
                    chunk_id=row.chunk_id,
                    document_id=row.document_id,
                    user_id=row.user_id,
                    content=content,
                    parent_content=None,  # see note above; populate in v0.1.1
                    entity_ids=entity_ids,
                    raw_quote_hint=content[:80],
                    page=meta.get("page"),
                    embedding_distance=float(row.distance) if row.distance is not None else 0.0,
                    document_deleted_at=row.doc_deleted_at,
                )
            )
        return retrieved
```

# apps/api/adelia/services/chat_repo.py
from datetime import datetime, timezone
from uuid import UUID

import sqlalchemy as sa

from adelia.db import AsyncSessionLocal
from adelia.models import ChatMessage, ChatSession
from adelia.schemas import ChatMessageOut, ChatSessionDetailOut, ChatSessionOut, Citation


async def create_session(*, user_id: UUID, title: str | None = None) -> ChatSessionOut:
    async with AsyncSessionLocal() as session:
        chat = ChatSession(user_id=user_id, title=title or "Nueva conversación")
        session.add(chat)
        await session.commit()
        await session.refresh(chat)
        return ChatSessionOut.model_validate(chat)


async def list_sessions(*, user_id: UUID) -> list[ChatSessionOut]:
    async with AsyncSessionLocal() as session:
        stmt = (
            sa.select(ChatSession)
            .where(
                ChatSession.user_id == user_id,
                ChatSession.deleted_at.is_(None),
            )
            .order_by(ChatSession.updated_at.desc())
        )
        result = await session.execute(stmt)
        rows = result.scalars().all()
        return [ChatSessionOut.model_validate(r) for r in rows]


async def get_session_with_messages(
    *, session_id: UUID, user_id: UUID
) -> ChatSessionDetailOut | None:
    async with AsyncSessionLocal() as session:
        chat = await session.get(ChatSession, session_id)
        if chat is None or chat.user_id != user_id or chat.deleted_at is not None:
            return None
        msg_stmt = (
            sa.select(ChatMessage)
            .where(ChatMessage.session_id == session_id)
            .order_by(ChatMessage.created_at.asc())
        )
        msg_result = await session.execute(msg_stmt)
        msgs = msg_result.scalars().all()
        message_outs = [
            ChatMessageOut(
                id=m.id,
                session_id=m.session_id,
                role=m.role,
                content=m.content,
                citations=[Citation(**c) for c in (m.citations or [])],
                created_at=m.created_at,
            )
            for m in msgs
        ]
        return ChatSessionDetailOut(
            id=chat.id,
            title=chat.title,
            created_at=chat.created_at,
            updated_at=chat.updated_at,
            messages=message_outs,
        )


async def persist_message(
    *,
    session_id: UUID,
    user_id: UUID,
    role: str,
    content: str,
    citations: list[Citation] | None,
) -> ChatMessageOut:
    async with AsyncSessionLocal() as session:
        msg = ChatMessage(
            session_id=session_id,
            user_id=user_id,
            role=role,
            content=content,
            citations=[c.model_dump(mode="json") for c in citations] if citations else None,
        )
        session.add(msg)
        # Touch session.updated_at so list_sessions ordering reflects recency
        chat = await session.get(ChatSession, session_id)
        if chat is not None:
            chat.updated_at = datetime.now(timezone.utc)
        await session.commit()
        await session.refresh(msg)
        return ChatMessageOut(
            id=msg.id,
            session_id=msg.session_id,
            role=msg.role,
            content=msg.content,
            citations=[Citation(**c) for c in (msg.citations or [])],
            created_at=msg.created_at,
        )


async def delete_session(*, session_id: UUID, user_id: UUID) -> bool:
    """Soft-delete a session. Returns True on success, False if not found/not owned."""
    async with AsyncSessionLocal() as session:
        chat = await session.get(ChatSession, session_id)
        if chat is None or chat.user_id != user_id or chat.deleted_at is not None:
            return False
        chat.deleted_at = datetime.now(timezone.utc)
        await session.commit()
        return True
```

# apps/api/adelia/services/chat_orchestrator.py
from __future__ import annotations

import logging
from collections.abc import AsyncIterator
from dataclasses import dataclass, field
from typing import Literal
from uuid import UUID

from mistralai.client.sdk import Mistral

from adelia.config import settings
from adelia.schemas import Citation
from adelia.services.retrieval import retrieve_relevant_chunks
from adelia.services.structured_query import query_observations_by_name_and_date_range
from adelia.services.temporal import detect_temporal_intent
from adelia.workers.embed import embed_texts


logger = logging.getLogger(__name__)


@dataclass
class ChatEvent:
    type: Literal["token", "final", "error"]
    content: str = ""
    citations: list[Citation] = field(default_factory=list)


_SYSTEM_PROMPT = """Eres un asistente médico que responde EXCLUSIVAMENTE basándote en
los fragmentos de la historia clínica del usuario proporcionados como contexto.

Reglas estrictas:
- Si la información no está en el contexto, di "No tengo información suficiente".
- Cita los fragmentos con marcadores numéricos [1], [2], ... que corresponden
  al orden de los fragmentos del contexto.
- Responde en español, en un párrafo corto.
- NUNCA inventes datos médicos. NUNCA des consejos médicos definitivos.
- Termina con "Verifica con tu médico antes de tomar decisiones clínicas."
"""


def _format_rag_context(chunks: list) -> str:
    """Format retrieved chunks as numbered context for the LLM prompt."""
    lines = []
    for i, c in enumerate(chunks, start=1):
        lines.append(f"[{i}] {c.content}")
    return "\n\n".join(lines)


def _format_temporal_context(rows: list[dict]) -> str:
    """Format structured-query rows as a numbered table for the LLM prompt."""
    lines = []
    for i, r in enumerate(rows, start=1):
        value = r.get("value") or {}
        v_str = (
            f"{value.get('value')} {value.get('unit') or ''}".strip()
            if isinstance(value, dict)
            else str(value)
        )
        date_str = r.get("event_date").isoformat() if r.get("event_date") else "fecha desconocida"
        lines.append(f"[{i}] {r['name']} = {v_str} ({date_str})")
    return "\n\n".join(lines)


async def _stream_llm_tokens(
    system_prompt: str, user_message: str
) -> AsyncIterator[str]:
    """Stream tokens from Mistral. Yields one token-substring per chunk.

    Raises RuntimeError if MISTRAL_API_KEY missing.
    """
    if not settings.mistral_api_key:
        raise RuntimeError("MISTRAL_API_KEY not set")

    client = Mistral(api_key=settings.mistral_api_key)
    response = await client.chat.stream_async(
        model="mistral-medium-latest",
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_message},
        ],
        temperature=0.2,
    )
    async for event in response:
        if event.data and event.data.choices:
            delta = event.data.choices[0].delta
            piece = getattr(delta, "content", "") or ""
            if piece:
                yield piece


async def answer_question_streaming(
    *, user_id: UUID, question: str
) -> AsyncIterator[ChatEvent]:
    """Main orchestrator: detect temporal intent → retrieve context → stream LLM.

    Yields ChatEvent(type='token', content=...) for each LLM token, then a
    single ChatEvent(type='final', citations=[...]) at the end. On error,
    yields ChatEvent(type='error', content=<message>).
    """
    citations: list[Citation] = []
    try:
        temporal = detect_temporal_intent(question)
        if temporal is not None:
            rows = await query_observations_by_name_and_date_range(
                user_id=user_id,
                name_substring=temporal.entity_name,
                from_date=temporal.from_date,
                to_date=temporal.to_date,
            )
            context = _format_temporal_context(rows)
            user_msg = (
                f"Pregunta del usuario: {question}\n\n"
                f"Datos estructurados de observaciones:\n{context}"
            )
            # Map each row to a Citation surrogate (chunk_id ← entity id)
            for r in rows:
                citations.append(
                    Citation(
                        chunk_id=r["id"],
                        document_id=r["document_id"],
                        raw_quote=r["raw_quote"] or "",
                        page=None,
                    )
                )
        else:
            # Standard RAG path
            query_embeds = await embed_texts([question])
            chunks = await retrieve_relevant_chunks(
                user_id=user_id,
                query_embedding=query_embeds[0] if query_embeds else [0.0] * 1024,
                top_k=8,
            )
            context = _format_rag_context(chunks)
            user_msg = (
                f"Pregunta del usuario: {question}\n\n"

                        chunk_id=c.chunk_id,
                        document_id=c.document_id,

    except Exception as exc:  # noqa: BLE001 — surface to client as error event
        logger.exception("answer_question_streaming failed: %s", exc)

from sse_starlette.sse import EventSourceResponse

from adelia.schemas import ChatRequest, ChatSessionDetailOut, ChatSessionOut, Citation

router = APIRouter(prefix="/chat", tags=["chat"])


@router.get("/sessions", response_model=list[ChatSessionOut])
async def list_chat_sessions(
    user_id: Annotated[uuid.UUID, Depends(get_current_user_id)],

async def get_chat_session(
    session_id: uuid.UUID,

    if detail is None:
        raise HTTPException(status_code=404)
    return detail


@router.delete("/sessions/{session_id}", status_code=status.HTTP_204_NO_CONTENT)
async def delete_chat_session(
    session_id: uuid.UUID,
    user_id: Annotated[uuid.UUID, Depends(get_current_user_id)],
):
    ok = await delete_session(session_id=session_id, user_id=user_id)
    if not ok:
        raise HTTPException(status_code=404)
    return None


@router.post("")
async def post_chat(
    payload: ChatRequest,
    user_id: Annotated[uuid.UUID, Depends(get_current_user_id)],
):
    """SSE endpoint: streams ChatEvent JSON payloads back to the client.

    Event format (one event per yielded ChatEvent):
        event: token | final | error
        data: {"content": "...", "session_id": "...", "citations": [...]}
    """
    # Create or load session
    if payload.session_id is None:
        new_session = await create_session(user_id=user_id)
        session_id = new_session.id
    else:
        existing = await get_session_with_messages(
            session_id=payload.session_id, user_id=user_id
        )
        if existing is None:
            raise HTTPException(status_code=404)
        session_id = existing.id

    # Persist user message before streaming begins
    await persist_message(
        session_id=session_id,
        user_id=user_id,
        role="user",
        content=payload.question,
        citations=None,
    )

    async def event_publisher():
        assistant_content_parts: list[str] = []
        final_citations: list[Citation] = []
        try:
            async for event in answer_question_streaming(
                user_id=user_id, question=payload.question
            ):
                if event.type == "token":
                    assistant_content_parts.append(event.content)
                    yield {
                        "event": "token",
                        "data": json.dumps(
                            {"content": event.content, "session_id": str(session_id)}
                        ),
                    }
                elif event.type == "final":
                    final_citations = event.citations
                    yield {
                        "event": "final",
                        "data": json.dumps(
                            {
                                "session_id": str(session_id),
                                "citations": [c.model_dump(mode="json") for c in event.citations],
                            }
                        ),
                    }
                elif event.type == "error":
                    yield {
                        "event": "error",
                        "data": json.dumps({"content": event.content}),
                    }
        finally:
            # Persist assistant message even on partial failure (whatever we
            # streamed so far). If nothing streamed, still write an empty row
            # so the session reflects the attempt.
            assistant_content = "".join(assistant_content_parts)
            await persist_message(
                session_id=session_id,
                user_id=user_id,
                role="assistant",
                content=assistant_content,
                citations=final_citations,
            )

    return EventSourceResponse(event_publisher())

export type StreamEvent =
  | { type: "token"; content: string; session_id: string }
  | { type: "final"; session_id: string; citations: Citation[] }
  | { type: "error"; content: string };

export async function* streamChat(
  jwt: string,
  question: string,
  sessionId: string | null
): AsyncGenerator<StreamEvent> {
  const res = await fetch(`${API_URL}/chat`, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${jwt}`,
      Accept: "text/event-stream",
    },
    body: JSON.stringify({ session_id: sessionId, question }),
  });
  if (!res.ok || !res.body) {
    throw new Error(`streamChat failed: ${res.status}`);
  }

  const reader = res.body.getReader();
  const decoder = new TextDecoder();
  let buffer = "";

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, { stream: true });

    // SSE messages are separated by \n\n. Each message has lines like
    // "event: token" and "data: {...}".
    let blockEnd: number;
    while ((blockEnd = buffer.indexOf("\n\n")) !== -1) {
      const rawBlock = buffer.slice(0, blockEnd);
      buffer = buffer.slice(blockEnd + 2);
      const block = rawBlock.trim();
      if (!block) continue;

      let eventType = "message";
      const dataLines: string[] = [];
      for (const line of block.split("\n")) {
        if (line.startsWith("event:")) eventType = line.slice(6).trim();
        else if (line.startsWith("data:")) dataLines.push(line.slice(5).trim());
      }
      if (dataLines.length === 0) continue;
      let payload: Record<string, unknown>;
      try {
        payload = JSON.parse(dataLines.join("\n"));
      } catch {
        continue;
      }

      if (eventType === "token") {
        yield { type: "token", content: String(payload.content ?? ""), session_id: String(payload.session_id ?? "") };
      } else if (eventType === "final") {
        yield {
          type: "final",
          session_id: String(payload.session_id ?? ""),
          citations: (payload.citations as Citation[]) ?? [],
        };
      } else if (eventType === "error") {
        yield { type: "error", content: String(payload.content ?? "unknown error") };
      }
    }
  }
}

    scrollRef.current?.scrollTo({ top: scrollRef.current.scrollHeight, behavior: "smooth" });
  }, [messages, busy]);

  const loadSession = useCallback(async (id: string) => {
    setActiveId(id);
    const detail = await getChatSession(id);
    setMessages(
      detail.messages.map((m) => ({
        role: m.role,
        content: m.content,
        citations: m.citations,
      }))
    );
  }, []);

  const newSession = useCallback(() => {
    setActiveId(null);
    setMessages([]);
  }, []);

  const handleDelete = useCallback(async (id: string) => {
    await deleteChatSession(id);
    setSessions((prev) => prev.filter((s) => s.id !== id));
    if (activeId === id) {
      setActiveId(null);
      setMessages([]);
    }
  }, [activeId]);

  const handleSubmit = useCallback(async (text: string) => {
    setBusy(true);
    const userMsg: LocalMsg = { role: "user", content: text, citations: [] };
    setMessages((prev) => [...prev, userMsg, { role: "assistant", content: "", citations: [] }]);
    try {
      let createdSessionId: string | null = null;
      for await (const event of streamChat(jwt, text, activeId)) {
        if (event.type === "token") {
          createdSessionId = createdSessionId ?? event.session_id;
          setMessages((prev) => {
            const updated = [...prev];
            const last = updated[updated.length - 1];
            if (last.role === "assistant") {
              updated[updated.length - 1] = { ...last, content: last.content + event.content };
            }
            return updated;
          });
        } else if (event.type === "final") {
          createdSessionId = createdSessionId ?? event.session_id;
          setMessages((prev) => {
            const updated = [...prev];
            const last = updated[updated.length - 1];
            if (last.role === "assistant") {
              updated[updated.length - 1] = { ...last, citations: event.citations };
            }
            return updated;
          });
        } else if (event.type === "error") {
          setMessages((prev) => {
            const updated = [...prev];
            const last = updated[updated.length - 1];
            if (last.role === "assistant") {
              updated[updated.length - 1] = { ...last, content: `Error: ${event.content}` };
            }
            return updated;
          });
        }
      }
      if (createdSessionId && !activeId) {
        setActiveId(createdSessionId);
        const refreshed = await listChatSessions().catch(() => sessions);
        setSessions(refreshed);
      }
    } catch (e) {
      setMessages((prev) => {
        const updated = [...prev];
        const last = updated[updated.length - 1];
        if (last.role === "assistant" && !last.content) {
          updated[updated.length - 1] = { ...last, content: `Error: ${String(e)}` };
        }
        return updated;
      });
    } finally {
      setBusy(false);
    }
  }, [activeId, jwt, sessions]);

  return (
    <div className="flex w-full">
      <ChatSessionsSidebar
        sessions={sessions}
        activeId={activeId}
        onSelect={loadSession}
        onNew={newSession}
        onDelete={handleDelete}
      />
      <section className="flex flex-1 flex-col">
        <header className="border-b border-slate-200 bg-white px-6 py-4">
          <h1 className="text-base font-semibold">{titleText}</h1>
        </header>
        <div ref={scrollRef} className="flex-1 overflow-y-auto bg-slate-50 px-6 py-6">
          <div className="mx-auto max-w-3xl space-y-3">
            {messages.map((m, i) => (
              <ChatMessageBubble key={i} message={m} locale={locale} />
            ))}
          </div>
        </div>
        <ChatInput onSubmit={handleSubmit} disabled={busy} />
      </section>
    </div>
  );
}
```
