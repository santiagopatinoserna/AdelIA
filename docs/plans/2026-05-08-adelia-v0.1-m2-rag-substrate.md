# AdelIA v0.1 — M2 RAG Substrate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire up the RAG substrate that M3 (LLM chat) and M5 (briefing generator) need: audio transcription, FHIR-aligned entity extraction, hierarchical chunking, and embeddings. After M2, every uploaded document yields `raw_text` + populated `entities` table + populated `chunks` table with vector embeddings ready for retrieval.

**Architecture:** Four pure async worker modules (`transcribe.py`, `extract.py`, `chunker.py`, `embed.py`) — each with a single responsibility, testable in isolation. The orchestrator `process_document` (already wired in M1-T8) chains them together. Whisper API (OpenAI BYOK) for audio. Mistral La Plateforme (existing `MISTRAL_API_KEY`) for entity extraction with prompt-engineered JSON validated by Pydantic. Hierarchical chunker is pure Python (token-counted via `tiktoken`). `mistral-embed` 1024-dim for vectors.

**Tech Stack additions:**
- `openai>=1.50` — Whisper API client (BYOK `OPENAI_API_KEY`)
- `tiktoken>=0.7` — token counting for chunk sizing
- `mistralai>=1.2` — Mistral SDK for entity extraction + embeddings (consolidates from raw HTTP in M1)

**Out of scope for M2 (deferred to M3+):** RAG retrieval, chat UI, briefing generator, sharing surfaces, frontend changes beyond a small entity/chunk count badge on detail page (optional, can defer).

**Time estimate (1h/day):** ~20-30h, ~3-4 weeks at 1h/day. Larger than the average M1 task because (b) chunk-aware-of-entities couples extraction → chunking ordering.

**Acceptance test (M2 done):** Upload a PDF or audio file. Background pipeline transcribes (if audio) → OCR (if PDF/image) → extracts ≥3 medical entities with `raw_quote` citations → produces hierarchical chunks tagged with entity_ids → generates 1024-dim embeddings. `entities` table has rows for that document. `chunks` table has rows with non-null embeddings.

```python
# apps/api/adelia/workers/transcribe.py
import io

from openai import AsyncOpenAI

from adelia.config import settings


def _ext_from_mime(mime_type: str) -> str:
    return {
        "audio/wav": "wav",
        "audio/mpeg": "mp3",
        "audio/mp3": "mp3",
        "audio/mp4": "m4a",
        "audio/x-m4a": "m4a",
        "audio/ogg": "ogg",
        "audio/webm": "webm",
        "audio/flac": "flac",
    }.get(mime_type, "wav")


async def transcribe_audio(body: bytes, mime_type: str) -> str:
    """Transcribe audio via OpenAI Whisper API.

    Args:
        body: raw audio bytes.
        mime_type: one of audio/wav, audio/mpeg, audio/mp4, audio/ogg, audio/webm, audio/flac.

    Returns:
        Transcribed text. Empty string if Whisper returns empty (e.g., silent audio).

    Raises:
        RuntimeError: if OPENAI_API_KEY is not configured. Configuration error —
            do NOT retry; alert.
        openai.APIError: if the OpenAI API returns an error. May be transient
            (rate limits, 5xx) — caller should consider retry with backoff.
    """
    if not settings.openai_api_key:
        raise RuntimeError("OPENAI_API_KEY not set")

    client = AsyncOpenAI(api_key=settings.openai_api_key)
    ext = _ext_from_mime(mime_type)
    file_tuple = (f"upload.{ext}", io.BytesIO(body), mime_type)

    response = await client.audio.transcriptions.create(
        model="whisper-1",
        file=file_tuple,
        response_format="text",
    )
    return response if isinstance(response, str) else str(response)
```

```python
# apps/api/adelia/workers/extract.py
import json
import re

from mistralai import Mistral
from pydantic import ValidationError

from adelia.config import settings
from adelia.schemas import ExtractedEntity


SYSTEM_PROMPT = """You are a medical information extraction assistant.

Given a medical document (clinical note, lab result, prescription, discharge summary),
extract structured entities.

Each entity MUST include:
- entity_type: one of condition, medication, allergy, immunization, procedure,
  observation, family_history, device, allergen_reaction, social_history
- name: human-readable name (e.g., "Metformin", "Type 2 Diabetes Mellitus")
- raw_quote: the EXACT verbatim text from the document that supports this entity.
  This is critical — it must be a substring of the input document character-for-character.
  Do not paraphrase. Do not summarize. Copy the exact text.
- confidence: 0.0 to 1.0, your self-rated certainty

Optional fields:
- value: dict with entity-specific data (e.g., {"dose": "500 mg", "freq": "BID"} for
  medications, {"value": 6.8, "unit": "%"} for observations)
- event_date: ISO date string YYYY-MM-DD if a date is present
- status: "active", "resolved", "completed" for conditions; "current" for medications
- coding_system: "ICD10", "SNOMED", "LOINC", "ATC", "RxNorm" if you can confidently code
- code: the code itself
- page: page number if multi-page

Return ONLY a JSON object: {"entities": [...]}. No prose, no markdown fence, just JSON.

If the document contains no medical information, return {"entities": []}.
"""


JSON_BLOCK_RE = re.compile(r"\{.*\}", re.DOTALL)


async def extract_entities(text: str) -> list[ExtractedEntity]:
    """Extract FHIR-aligned medical entities from raw text via Mistral LLM.

    Args:
        text: raw_text from a document (post-OCR or post-transcription).

    Returns:
        List of ExtractedEntity. Entities whose raw_quote does NOT appear verbatim
        in the input text are filtered out (anti-hallucination guard).

    Raises:
        RuntimeError: if MISTRAL_API_KEY is not configured.
        mistralai.MistralError: on API failure.
    """
    if not settings.mistral_api_key:
        raise RuntimeError("MISTRAL_API_KEY not set")

    client = Mistral(api_key=settings.mistral_api_key)

    response = await client.chat.complete_async(
        model="mistral-medium-latest",
        messages=[
            {"role": "system", "content": SYSTEM_PROMPT},
            {"role": "user", "content": f"Document:\n\n{text}"},
        ],
        response_format={"type": "json_object"},
        temperature=0.0,
    )

    content = response.choices[0].message.content if response.choices else ""
    if not isinstance(content, str):
        content = str(content)

    # Strip optional markdown fences just in case the model violates response_format.
    match = JSON_BLOCK_RE.search(content)
    if not match:
        return []
    payload = json.loads(match.group(0))

    raw_entities = payload.get("entities", []) if isinstance(payload, dict) else []
    validated: list[ExtractedEntity] = []
    for raw in raw_entities:
        try:
            entity = ExtractedEntity(**raw)
        except ValidationError:
            continue
        # Anti-hallucination: raw_quote MUST appear verbatim in the input text.
        if entity.raw_quote and entity.raw_quote in text:
            validated.append(entity)
    return validated
```

```python
# apps/api/adelia/workers/chunker.py
from dataclasses import dataclass, field

import tiktoken

# Use cl100k encoding (GPT-3.5/4/4o); good enough for token-budget estimation.
# We are not optimizing for any specific LLM token budget — the goal is
# predictable, reproducible chunk sizes.
_ENCODING = tiktoken.get_encoding("cl100k_base")


def count_tokens(text: str) -> int:
    if not text:
        return 0
    return len(_ENCODING.encode(text))


@dataclass(frozen=True)
class ChunkConfig:
    small_size: int = 350
    parent_size: int = 1500
    overlap: int = 50


@dataclass
class SmallChunk:
    content: str
    chunk_index: int
    parent_index: int
    token_count: int
    start_char: int
    end_char: int
    entity_ids: list[str] = field(default_factory=list)


@dataclass
class ParentChunk:
    content: str
    parent_index: int
    token_count: int
    start_char: int
    end_char: int


@dataclass
class ChunkOutput:
    small_chunks: list[SmallChunk]
    parent_chunks: list[ParentChunk]


def _split_by_token_window(text: str, target_tokens: int, overlap_tokens: int) -> list[tuple[str, int, int]]:
    """Split text into windows of ~target_tokens tokens with overlap_tokens overlap.

    Returns list of (chunk_text, start_char, end_char). Walks character-by-character
    to find token boundaries; not the fastest implementation, but predictable
    and correct for chunk sizes typical of medical documents (<10k tokens).
    """
    if not text:
        return []
    tokens = _ENCODING.encode(text)
    if len(tokens) <= target_tokens:
        return [(text, 0, len(text))]

    chunks: list[tuple[str, int, int]] = []
    step = max(1, target_tokens - overlap_tokens)
    for start_tok in range(0, len(tokens), step):
        end_tok = min(start_tok + target_tokens, len(tokens))
        window_tokens = tokens[start_tok:end_tok]
        window_text = _ENCODING.decode(window_tokens)
        # Find this window in the original text. tiktoken roundtrip is lossy
        # at the byte level (especially for unicode); fall back to best-effort
        # char approximation if needed.
        start_char = text.find(window_text)
        if start_char < 0:
            # Approximate: char position scales linearly with token position.
            # Acceptable for ASCII-heavy medical English.
            start_char = int(len(text) * start_tok / len(tokens))
        end_char = start_char + len(window_text)
        chunks.append((window_text, start_char, end_char))
        if end_tok == len(tokens):
            break
    return chunks


def chunk_hierarchical(
    text: str,
    config: ChunkConfig | None = None,
    entity_ranges: dict[str, tuple[int, int]] | None = None,
) -> ChunkOutput:
    """Hierarchical chunker producing small + parent chunks.

    Args:
        text: source text (post-OCR or post-transcription).
        config: chunk size config; defaults to ChunkConfig().
        entity_ranges: optional map of entity_id -> (start_char, end_char)
            in the source text. When provided, each small chunk gets an
            entity_ids list of entities that overlap its char range.

    Returns:
        ChunkOutput with small_chunks (300-400 token slices) and parent_chunks
        (1500 token spans). Each small chunk has parent_index pointing into
        parent_chunks for context expansion at retrieval time.
    """
    cfg = config or ChunkConfig()
    ranges = entity_ranges or {}

    parent_windows = _split_by_token_window(text, cfg.parent_size, overlap_tokens=0)
    parent_chunks: list[ParentChunk] = []
    for i, (chunk_text, sc, ec) in enumerate(parent_windows):
        parent_chunks.append(
            ParentChunk(
                content=chunk_text,
                parent_index=i,
                token_count=count_tokens(chunk_text),
                start_char=sc,
                end_char=ec,
            )
        )

    if not parent_chunks:
        return ChunkOutput(small_chunks=[], parent_chunks=[])

    small_chunks: list[SmallChunk] = []
    for parent_idx, parent in enumerate(parent_chunks):
        small_windows = _split_by_token_window(
            parent.content, cfg.small_size, overlap_tokens=cfg.overlap
        )
        for j, (chunk_text, sc_local, ec_local) in enumerate(small_windows):
            sc_global = parent.start_char + sc_local
            ec_global = parent.start_char + ec_local
            entity_ids = [
                eid
                for eid, (e_start, e_end) in ranges.items()
                if e_start < ec_global and e_end > sc_global
            ]
            small_chunks.append(
                SmallChunk(
                    content=chunk_text,
                    chunk_index=len(small_chunks),
                    parent_index=parent_idx,
                    token_count=count_tokens(chunk_text),
                    start_char=sc_global,
                    end_char=ec_global,
                    entity_ids=entity_ids,
                )
            )

    return ChunkOutput(small_chunks=small_chunks, parent_chunks=parent_chunks)
```

```python
from mistralai import Mistral

async def embed_texts(texts: list[str]) -> list[list[float]]:
    """Embed a batch of texts using Mistral's mistral-embed model (1024-dim).

    Args:
        texts: list of input strings.

    Returns:
        List of 1024-dim vectors aligned 1:1 with input texts. Empty list
        for empty input.

    Raises:
        RuntimeError: if MISTRAL_API_KEY is not configured.
        mistralai.MistralError: on API failure.

        return []
    if not settings.mistral_api_key:

    client = Mistral(api_key=settings.mistral_api_key)
    response = await client.embeddings.create_async(
        model="mistral-embed",
        inputs=texts,
    )
    return [item.embedding for item in response.data]
```

```python
async def process_document(document_id: uuid.UUID, mime_type: str) -> None:
    """BackgroundTask: download from S3, transcribe/OCR, extract entities,
    chunk + embed. Persist all stages atomically per document."""
    async with AsyncSessionLocal() as session:
        doc = await session.get(Document, document_id)
        if doc is None:
            return
        try:
            body_stream = await storage.get_object(doc.s3_key)
            body = await asyncio.to_thread(body_stream.read)

            # Stage 1: Get raw text via transcribe (audio) or OCR (pdf/image)
            if _is_audio(mime_type):
                raw_text = await transcribe_audio(body, mime_type)
            elif mime_type == "application/pdf" or mime_type.startswith("image/"):
                raw_text = await extract_text_from_pdf(body, mime_type)
            else:
                raw_text = ""

            doc.raw_text = raw_text
            await session.flush()  # ensure doc.id usable for FKs below

            # Stage 2: Entity extraction → persist entities table
            entity_records: list[Entity] = []
            entity_ranges: dict[str, tuple[int, int]] = {}
            if raw_text:
                extracted: list[ExtractedEntity] = await extract_entities(raw_text)
                for ex in extracted:
                    # Find exact char range of raw_quote in raw_text
                    start_char = raw_text.find(ex.raw_quote)
                    end_char = start_char + len(ex.raw_quote) if start_char >= 0 else -1
                    entity = Entity(
                        user_id=doc.user_id,
                        document_id=doc.id,
                        entity_type=ex.entity_type,
                        coding_system=ex.coding_system,
                        code=ex.code,
                        name=ex.name,
                        value=ex.value,
                        event_date=ex.event_date,
                        status=ex.status,
                        provenance="extracted_from_clinician_doc",
                        confidence=ex.confidence,
                        raw_quote=ex.raw_quote,
                        page=ex.page,
                        needs_review=ex.confidence < 0.7,
                    )
                    session.add(entity)
                    entity_records.append(entity)
                await session.flush()  # populate entity.id for FK use
                for ent in entity_records:
                    if ent.raw_quote and ent.raw_quote in raw_text:
                        s = raw_text.find(ent.raw_quote)
                        entity_ranges[str(ent.id)] = (s, s + len(ent.raw_quote))

            # Stage 3: Hierarchical chunking
            chunk_records: list[Chunk] = []
            chunk_texts: list[str] = []
            if raw_text:
                chunk_output = chunk_hierarchical(
                    raw_text,
                    ChunkConfig(small_size=350, parent_size=1500, overlap=50),
                    entity_ranges=entity_ranges,
                )
                for sc in chunk_output.small_chunks:
                    chunk_records.append(
                        Chunk(
                            document_id=doc.id,
                            user_id=doc.user_id,
                            content=sc.content,
                            chunk_index=sc.chunk_index,
                            chunk_metadata={
                                "parent_index": sc.parent_index,
                                "token_count": sc.token_count,
                                "start_char": sc.start_char,
                                "end_char": sc.end_char,
                                "entity_ids": sc.entity_ids,
                            },
                        )
                    )
                    chunk_texts.append(sc.content)

            # Stage 4: Embed chunks → set Chunk.embedding
            if chunk_texts:
                vectors = await embed_texts(chunk_texts)
                for chunk_record, vec in zip(chunk_records, vectors, strict=True):
                    chunk_record.embedding = vec
                    session.add(chunk_record)
        except (RuntimeError, httpx.HTTPStatusError, ClientError, EndpointConnectionError, OpenAIAPIError) as exc:
            logger.exception(
                "process_document failed for document_id=%s: %s",
                document_id,
                exc,
            )
            doc.raw_text = doc.raw_text or None
        except Exception as exc:  # noqa: BLE001 — final fallback to set processed_at
            logger.exception(
                "process_document unexpected failure for document_id=%s: %s",
                document_id,
                exc,
            )
            doc.raw_text = doc.raw_text or None
        finally:
            doc.processed_at = datetime.now(timezone.utc)
            await session.commit()
```
