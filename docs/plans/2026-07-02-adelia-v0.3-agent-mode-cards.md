# AdelIA v0.3 — Agent Mode + Dynamic Cards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn AdelIA's home into a mobile-first conversational agent that tool-calls existing services and streams typed, dynamic cards (chat + card rail on desktop, inline cards on mobile), pediatric- and multi-profile-aware.

**Architecture:** New backend `agent_orchestrator` runs a Claude-driven tool-calling loop over thin adapters to existing services (retrieval, briefing, enrichment, profiles, pediatric), emitting an `AgentEvent` async stream that a new `/agent` router maps to SSE. New frontend `AgentCanvas` reuses the existing SSE reader pattern, renders a discriminated-union of `<Card*>` components, and threads an active `profile_id` through the stream. Everything wraps existing code; the classic dashboard survives behind "ver todo".

**Tech Stack:** Backend — Python 3.12, FastAPI, `sse-starlette`, Anthropic SDK (new dep), SQLAlchemy 2 async, pytest (`uv run pytest`). Frontend — Next.js 15 App Router, React 19, next-intl 4, Tailwind v4, Playwright (`pnpm --filter @adelia/web`).

## Global Constraints

- Python `>=3.12`; run tests with `uv run pytest -q` (from `apps/api`); lint `uv run ruff check .`; `asyncio_mode = "auto"` (no `@pytest.mark.asyncio` needed for non-DB tests).
- DB-bound tests gate on `from tests.pg_gate import PG_AVAILABLE` + `@pytest.mark.skipif(not PG_AVAILABLE, ...)` and use `from tests.db_helpers import make_user`.
- Config is a module singleton: `from adelia.config import settings` (NO `get_settings()`).
- Every API route depends on `user_id: Annotated[uuid.UUID, Depends(get_current_user_id)]`.
- SSE uses `EventSourceResponse` from `sse_starlette.sse`; yield dicts `{"event": <name>, "data": <json str>}`.
- All service session args are keyword-only; retrieval/orchestrators own their own `AsyncSessionLocal()`; profile/enrichment take `session` as first positional arg.
- Frontend: import `Link` from `@/lib/navigation` (never `next/link`); path alias `@/` = web root; never import `lib/api-client.ts` (server) into a `"use client"` file.
- i18n: any new key MUST exist in all three `messages/{es,en,fr}.json` (es is source of truth); CI has a catalog-parity check.
- Autonomy rule (spec §3-Q4): read/analyze tools execute immediately; write tools (`generar_briefing`, `compartir`, `completar_perfil`, `soft_delete`) MUST emit a `card.confirm` and only run after a follow-up confirm action.
- Tap targets `min-h-[44px]`; mobile-first, `md:` (768px) primary breakpoint; full-height panes `h-[calc(100dvh-3.5rem)]` (header is `h-14`).
- Claude brain behind a provider interface so BYOK/Mistral can swap later. Default agent model `claude-sonnet-5`; keep Mistral for OCR/embeddings.

```python
# apps/api/adelia/agent/cards.py
from __future__ import annotations
from typing import Any

def _card(card_type: str, card_id: str, payload: dict, actions: list[dict] | None = None) -> dict:
    return {"type": card_type, "id": card_id, "payload": payload, "actions": actions or []}

def card_action(card_id: str, title: str, body: str, action_label: str, action_intent: str) -> dict:
    return _card("action", card_id, {"title": title, "body": body},
                 [{"label": action_label, "intent": action_intent}])

def card_confirm(card_id: str, title: str, tool_name: str, tool_args: dict[str, Any]) -> dict:
    return _card("confirm", card_id, {"title": title, "tool_name": tool_name, "tool_args": tool_args},
                 [{"label": "Sí", "intent": "confirm"}, {"label": "No", "intent": "cancel"}])

def card_question(card_id: str, field: str, prompt: str, input_type: str = "text") -> dict:
    return _card("question", card_id, {"field": field, "prompt": prompt, "input_type": input_type},
                 [{"label": "Guardar", "intent": "answer"}])

def card_lab(card_id: str, name: str, value: Any, unit: str, flag: str, range_str: str, interpretation: str) -> dict:
    return _card("lab", card_id, {"name": name, "value": value, "unit": unit, "flag": flag,
                                  "range": range_str, "interpretation": interpretation})

def card_briefing(card_id: str, briefing_id: str, specialty: str, status: str, preview: str) -> dict:
    return _card("briefing", card_id, {"briefing_id": briefing_id, "specialty": specialty,
                                       "status": status, "preview": preview},
                 [{"label": "Ver PDF", "intent": "open_briefing"}, {"label": "Compartir", "intent": "share_briefing"}])

def card_document(card_id: str, document_id: str, filename: str, status: str, entities: int) -> dict:
    return _card("document", card_id, {"document_id": document_id, "filename": filename,
                                       "status": status, "entities": entities})

def card_profile(card_id: str, profiles: list[dict], active_id: str | None) -> dict:
    return _card("profile", card_id, {"profiles": profiles, "active_id": active_id})

def card_insight(card_id: str, title: str, body: str, tone: str = "neutral") -> dict:
    return _card("insight", card_id, {"title": title, "body": body, "tone": tone})
```

```python
# apps/api/adelia/agent/pediatrics.py
from __future__ import annotations
import json
from functools import lru_cache
from pathlib import Path

_DATA = Path(__file__).parent / "data"

@lru_cache(maxsize=1)
def _growth() -> dict:
    return json.loads((_DATA / "who_growth.json").read_text(encoding="utf-8"))

@lru_cache(maxsize=1)
def _vaccines() -> list[dict]:
    return json.loads((_DATA / "vaccines_es.json").read_text(encoding="utf-8"))

# maps a percentile band edge to its numeric percentile
_BANDS = [("p3", 3), ("p15", 15), ("p50", 50), ("p85", 85), ("p97", 97)]

def growth_percentile(*, metric: str, value: float, age_months: int, sex: str) -> int | None:
    table = _growth().get(metric, {}).get(sex)
    if not table:
        return None
    row = next((r for r in table if r["age_months"] == age_months), None)
    if row is None:
        return None
    # piecewise-linear interpolation across the known band edges
    edges = [(row[k], p) for k, p in _BANDS]
    if value <= edges[0][0]:
        return edges[0][1]
    if value >= edges[-1][0]:
        return edges[-1][1]
    for (v_lo, p_lo), (v_hi, p_hi) in zip(edges, edges[1:]):
        if v_lo <= value <= v_hi:
            frac = (value - v_lo) / (v_hi - v_lo) if v_hi != v_lo else 0.0
            return round(p_lo + frac * (p_hi - p_lo))
    return None

def due_vaccines(*, age_months: int) -> list[dict]:
    out = []
    for v in _vaccines():
        if v["due_month"] <= age_months + 1:  # due now or within a month
            out.append({"name": v["name"], "due_month": v["due_month"],
                        "overdue": v["due_month"] < age_months})
    return out
```

```python
# apps/api/adelia/agent/executor.py
from __future__ import annotations
from dataclasses import dataclass
from uuid import UUID, uuid4

from adelia.agent import cards
from adelia.agent.pediatrics import growth_percentile, due_vaccines
from adelia.enrichment.lab_ranges import evaluate as lab_evaluate
from adelia.enrichment.drug_interactions import check_interactions
from adelia.enrichment.trial_matcher import match_for_patient
from adelia.services.chat_orchestrator import answer_question_streaming

@dataclass
class ToolOutcome:
    text: str
    card: dict | None = None

def _cid() -> str:
    return uuid4().hex[:12]

async def execute_tool(name: str, args: dict, *, user_id: UUID, profile_id: UUID | None,
                       locale: str = "es") -> ToolOutcome:
    if name == "buscar_en_expediente":
        parts: list[str] = []
        async for ev in answer_question_streaming(user_id=user_id, question=args["query"], locale=locale):
            if ev.type == "token":
                parts.append(ev.content)
        return ToolOutcome(text="".join(parts) or "No encontré datos relevantes.")

    if name == "evaluar_labs":
        r = lab_evaluate(args["name"], args["value"])
        if r is None:
            return ToolOutcome(text=f"No tengo rango de referencia para {args['name']}.")
        card = cards.card_lab(_cid(), r.canonical_name, r.value, r.unit, r.flag, r.range, r.interpretation)
        return ToolOutcome(text=f"{r.canonical_name}: {r.value} {r.unit} ({r.interpretation}).", card=card)

    if name == "revisar_interacciones":
        found = check_interactions(args["medicamentos"])
        if not found:
            return ToolOutcome(text="No detecté interacciones conocidas.")
        top = found[0]
        body = f"{top.drug_a} + {top.drug_b}: {top.recommendation}"
        return ToolOutcome(text=f"{len(found)} interacción(es). {body}",
                           card=cards.card_insight(_cid(), "Interacción detectada", body, tone="warn"))

    if name == "buscar_ensayos":
        res = await match_for_patient(conditions=[args["condition"]], country=args.get("country"))
        trials = res.get(args["condition"], [])
        if not trials:
            return ToolOutcome(text="No encontré ensayos que coincidan.")
        body = "; ".join(getattr(t, "title", "") for t in trials[:3])
        return ToolOutcome(text=f"{len(trials)} ensayo(s).",
                           card=cards.card_insight(_cid(), "Ensayos clínicos", body))

    if name == "percentil_crecimiento":
        p = growth_percentile(metric=args["metric"], value=args["value"],
                              age_months=args["age_months"], sex=args["sex"])
        if p is None:
            return ToolOutcome(text="No pude calcular el percentil (fuera de tabla).")
        metric_es = "peso" if args["metric"] == "weight" else "talla"
        body = f"El {metric_es} está en el percentil {p}."
        tone = "warn" if p < 3 or p > 97 else "positive"
        return ToolOutcome(text=body, card=cards.card_insight(_cid(), "Percentil de crecimiento", body, tone=tone))

    if name == "proximas_vacunas":
        due = due_vaccines(age_months=args["age_months"])
        if not due:
            return ToolOutcome(text="No hay vacunas pendientes próximas.")
        body = ", ".join(d["name"] for d in due)
        overdue = any(d["overdue"] for d in due)
        return ToolOutcome(text=f"Próximas vacunas: {body}",
                           card=cards.card_insight(_cid(), "Vacunas", body, tone="warn" if overdue else "neutral"))

    if name == "generar_briefing":
        # WRITE tool: never executed here — orchestrator intercepts and emits a confirm card.
        return ToolOutcome(text="(pendiente de confirmación)")

    if name == "completar_perfil":
        return ToolOutcome(text="(pendiente de confirmación)")

    return ToolOutcome(text=f"Herramienta desconocida: {name}")
```

```python
# apps/api/adelia/agent/provider.py
from __future__ import annotations
from dataclasses import dataclass, field
from typing import AsyncIterator, Protocol

from adelia.config import settings

@dataclass
class ToolCall:
    id: str
    name: str
    args: dict

@dataclass
class ProviderStep:
    text: str = ""
    tool_calls: list[ToolCall] = field(default_factory=list)

class AgentProvider(Protocol):
    async def stream_step(self, *, system: str, messages: list[dict],
                          tools: list[dict]) -> AsyncIterator[dict]: ...

class AnthropicProvider:
    def __init__(self) -> None:
        from anthropic import AsyncAnthropic
        if not settings.anthropic_api_key:
            raise RuntimeError("ANTHROPIC_API_KEY not set")
        self._client = AsyncAnthropic(api_key=settings.anthropic_api_key)

    async def stream_step(self, *, system: str, messages: list[dict],
                          tools: list[dict]) -> AsyncIterator[dict]:
        async with self._client.messages.stream(
            model=settings.agent_model, max_tokens=1024, system=system,
            messages=messages, tools=tools,
        ) as stream:
            async for event in stream:
                if event.type == "text":
                    yield {"type": "token", "text": event.text}
            final = await stream.get_final_message()
        for block in final.content:
            if getattr(block, "type", None) == "tool_use":
                yield {"type": "tool_call", "id": block.id, "name": block.name, "args": block.input}
        yield {"type": "stop", "stop_reason": final.stop_reason}

def get_provider() -> AgentProvider:
    provider = settings.llm_provider
    if provider in ("anthropic", "", "mistral"):
        # default agent brain is Claude even if OCR/embeddings use Mistral
        return AnthropicProvider()
    raise RuntimeError(f"Agent provider not implemented: {provider}")
```

> Note: `stream_step` yields text tokens live, then tool_use blocks after the turn (Anthropic returns tool calls at the end of the assistant turn). The orchestrator consumes tokens as they arrive and acts on tool calls when the step stops.

```python
# apps/api/adelia/agent/orchestrator.py
from __future__ import annotations
from typing import AsyncIterator
from uuid import UUID, uuid4

from adelia.agent.events import AgentEvent
from adelia.agent import cards
from adelia.agent.tools import TOOLS, is_write_tool
from adelia.agent.executor import execute_tool
from adelia.agent.provider import get_provider

MAX_STEPS = 5

_RULES = {
    "es": "Eres AdelIA, una asistente de salud cálida y clara para madres ocupadas. "
          "Responde corto y sin jerga. Usa las herramientas para consultar datos; nunca inventes. "
          "Para acciones que escriben o comparten, propón y espera confirmación.",
    "en": "You are AdelIA, a warm, clear health assistant for busy moms. Be brief, no jargon. "
          "Use tools to look up data; never make things up. For write/share actions, propose and wait for confirmation.",
    "fr": "Tu es AdelIA, une assistante santé chaleureuse et claire pour les mamans occupées. "
          "Sois brève, sans jargon. Utilise les outils pour consulter les données ; n'invente jamais. "
          "Pour les actions d'écriture/partage, propose et attends la confirmation.",
}

def _system_prompt(locale: str) -> str:
    return _RULES.get(locale, _RULES["es"])

async def run_agent_turn(*, user_id: UUID, profile_id: UUID | None, message: str,
                         history: list[dict] | None = None, card_action: dict | None = None,
                         locale: str = "es") -> AsyncIterator[AgentEvent]:
    provider = get_provider()
    messages: list[dict] = list(history or [])

    # A confirm action arriving from the UI = execute the previously-proposed write tool now.
    if card_action and card_action.get("intent") == "confirm":
        name = card_action["tool_name"]
        args = card_action.get("tool_args", {})
        try:
            outcome = await _run_write_tool(name, args, user_id=user_id, profile_id=profile_id, locale=locale)
            if outcome.card:
                yield AgentEvent(type="card", card=outcome.card)
            yield AgentEvent(type="token", content=outcome.text)
            yield AgentEvent(type="final")
        except Exception as exc:  # noqa: BLE001
            yield AgentEvent(type="error", content=str(exc))
        return

    messages.append({"role": "user", "content": message})
    try:
        for _ in range(MAX_STEPS):
            assistant_text = ""
            tool_calls: list[dict] = []
            async for ev in provider.stream_step(system=_system_prompt(locale), messages=messages, tools=TOOLS):
                if ev["type"] == "token":
                    assistant_text += ev["text"]
                    yield AgentEvent(type="token", content=ev["text"])
                elif ev["type"] == "tool_call":
                    tool_calls.append(ev)
                elif ev["type"] == "stop":
                    pass
            if not tool_calls:
                yield AgentEvent(type="final")
                return
            # record the assistant turn (text + tool_use) for the next model call
            messages.append({"role": "assistant", "content": _assistant_blocks(assistant_text, tool_calls)})
            tool_results = []
            for tc in tool_calls:
                yield AgentEvent(type="tool_call", tool_name=tc["name"])
                if is_write_tool(tc["name"]):
                    confirm = cards.card_confirm(uuid4().hex[:12], _confirm_title(tc["name"], locale),
                                                 tc["name"], tc["args"])
                    yield AgentEvent(type="card", card=confirm)
                    yield AgentEvent(type="final")  # pause: wait for the user's confirm action
                    return
                outcome = await execute_tool(tc["name"], tc["args"], user_id=user_id,
                                             profile_id=profile_id, locale=locale)
                if outcome.card:
                    yield AgentEvent(type="card", card=outcome.card)
                tool_results.append({"type": "tool_result", "tool_use_id": tc["id"], "content": outcome.text})
            messages.append({"role": "user", "content": tool_results})
        yield AgentEvent(type="final")
    except Exception as exc:  # noqa: BLE001
        yield AgentEvent(type="error", content=str(exc))

def _assistant_blocks(text: str, tool_calls: list[dict]) -> list[dict]:
    blocks: list[dict] = []
    if text:
        blocks.append({"type": "text", "text": text})
    for tc in tool_calls:
        blocks.append({"type": "tool_use", "id": tc["id"], "name": tc["name"], "input": tc["args"]})
    return blocks

def _confirm_title(name: str, locale: str) -> str:
    titles = {"generar_briefing": {"es": "¿Genero el briefing para el especialista?",
                                   "en": "Generate the briefing for the specialist?",
                                   "fr": "Générer le briefing pour le spécialiste ?"},
              "completar_perfil": {"es": "¿Guardo este dato en el perfil?",
                                   "en": "Save this to the profile?",
                                   "fr": "Enregistrer dans le profil ?"}}
    return titles.get(name, {}).get(locale, titles.get(name, {}).get("es", "¿Confirmas?"))

async def _run_write_tool(name: str, args: dict, *, user_id: UUID, profile_id: UUID | None,
                          locale: str):
    from adelia.agent.executor import ToolOutcome
    from adelia.enrichment import profile_service
    from adelia.db import AsyncSessionLocal
    if name == "generar_briefing":
        from adelia.services import briefing_orchestrator
        from adelia.services.briefing_repo import create_briefing
        async with AsyncSessionLocal() as session:
            briefing = await create_briefing(session, user_id=user_id, target_specialty=args["specialty"])
            await session.commit()
            bid = briefing.id
        await briefing_orchestrator.run(briefing_id=bid, user_id=user_id,
                                        target_specialty=args["specialty"], locale=locale)
        from adelia.agent import cards
        return ToolOutcome(text="Briefing generado.",
                           card=cards.card_briefing(bid.hex[:12], str(bid), args["specialty"], "ready", ""))
    if name == "completar_perfil":
        async with AsyncSessionLocal() as session:
            pid = await profile_service.resolve_profile_id(session, user_id=user_id, profile_id=profile_id)
            # apply the field update via profile_service (add update_profile if missing — see Task 7a note)
            await session.commit()
        return ToolOutcome(text="Dato guardado en el perfil.")
    return ToolOutcome(text="(nada que hacer)")
```

```python
# apps/api/adelia/agent/suggestions.py
from __future__ import annotations
from dataclasses import dataclass
from uuid import UUID, uuid4

from adelia.agent import cards

@dataclass
class ProfileState:
    has_dob: bool
    unprocessed_docs: int
    stale_briefing: bool
    is_child: bool

def _cid() -> str:
    return uuid4().hex[:12]

async def _gather_state(*, user_id: UUID, profile_id: UUID | None) -> ProfileState:
    from adelia.db import AsyncSessionLocal
    from sqlalchemy import select, func
    from adelia.models import Document, Profile
    async with AsyncSessionLocal() as session:
        prof = None
        if profile_id is not None:
            prof = await session.get(Profile, profile_id)
        unprocessed = await session.scalar(
            select(func.count()).select_from(Document)
            .where(Document.user_id == user_id, Document.deleted_at.is_(None),
                   Document.processed_at.is_(None)))
        return ProfileState(
            has_dob=bool(prof and prof.date_of_birth),
            unprocessed_docs=int(unprocessed or 0),
            stale_briefing=False,
            is_child=bool(prof and prof.relationship == "child"))

async def build_suggestions(*, user_id: UUID, profile_id: UUID | None, locale: str = "es") -> list[dict]:
    state = await _gather_state(user_id=user_id, profile_id=profile_id)
    out: list[dict] = []
    if state.is_child and not state.has_dob:
        out.append(cards.card_question(_cid(), "date_of_birth",
                                       "¿Cuál es la fecha de nacimiento del bebé?", input_type="date"))
    if state.unprocessed_docs:
        out.append(cards.card_action(_cid(), "Documentos sin procesar",
                                     f"Tienes {state.unprocessed_docs} documento(s) por procesar.",
```

```python
import json

from typing import Annotated

from fastapi import APIRouter, Depends
from pydantic import BaseModel, Field
from sse_starlette.sse import EventSourceResponse

from adelia.auth import get_current_user_id
from adelia.agent.events import AgentEvent
from adelia.agent.orchestrator import run_agent_turn
from adelia.agent.suggestions import build_suggestions

router = APIRouter(prefix="/agent", tags=["agent"])

class CardAction(BaseModel):
    intent: str
    tool_name: str | None = None
    tool_args: dict | None = None

class AgentTurnRequest(BaseModel):
    message: str = Field(default="", max_length=4000)
    profile_id: uuid.UUID | None = None
    locale: str = "es"
    card_action: CardAction | None = None

def _map_event(event: AgentEvent) -> dict:
    if event.type == "token":
        return {"event": "token", "data": json.dumps({"content": event.content})}
    if event.type == "tool_call":
        return {"event": "tool_call", "data": json.dumps({"tool_name": event.tool_name})}
    if event.type == "card":
        return {"event": "card", "data": json.dumps({"card": event.card})}
    if event.type == "error":
        return {"event": "error", "data": json.dumps({"content": event.content})}
    return {"event": "final", "data": json.dumps({})}

@router.post("/turn")
async def post_turn(payload: AgentTurnRequest,
                    user_id: Annotated[uuid.UUID, Depends(get_current_user_id)]):
    card_action = payload.card_action.model_dump() if payload.card_action else None

    async def event_publisher():
        yield {"event": "start", "data": json.dumps({})}
        async for event in run_agent_turn(user_id=user_id, profile_id=payload.profile_id,
                                          message=payload.message, card_action=card_action,
                                          locale=payload.locale):
            yield _map_event(event)

    return EventSourceResponse(event_publisher())

@router.get("/suggestions")
async def get_suggestions(user_id: Annotated[uuid.UUID, Depends(get_current_user_id)],
                          profile_id: uuid.UUID | None = None, locale: str = "es"):
```

```ts
// apps/web/lib/agent-types.ts
export type AgentCard = {
  type: "action" | "confirm" | "question" | "lab" | "briefing" | "document" | "profile" | "insight";
  id: string;
  payload: Record<string, unknown>;
  actions: { label: string; intent: string }[];
};

export type AgentStreamEvent =
  | { type: "start" }
  | { type: "token"; content: string }
  | { type: "tool_call"; tool_name: string }
  | { type: "card"; card: AgentCard }
  | { type: "final" }
  | { type: "error"; content: string };

export function* parseAgentBlocks(
  read: () => string,
  write: (rest: string) => void,
): Generator<AgentStreamEvent> {
  let buffer = read().replace(/\r\n/g, "\n");
  let idx: number;
  while ((idx = buffer.indexOf("\n\n")) !== -1) {
    const block = buffer.slice(0, idx);
    buffer = buffer.slice(idx + 2);
    let eventType = "";
    let dataStr = "";
    for (const line of block.split("\n")) {
      if (line.startsWith("event:")) eventType = line.slice(6).trim();
      else if (line.startsWith("data:")) dataStr += line.slice(5).trim();
    }
    if (!eventType) continue;
    let data: Record<string, unknown> = {};
    try { data = dataStr ? JSON.parse(dataStr) : {}; }
    catch { console.warn("agent: bad SSE data", dataStr); continue; }
    switch (eventType) {
      case "start": yield { type: "start" }; break;
      case "token": yield { type: "token", content: String(data.content ?? "") }; break;
      case "tool_call": yield { type: "tool_call", tool_name: String(data.tool_name ?? "") }; break;
      case "card": yield { type: "card", card: data.card as AgentCard }; break;
      case "final": yield { type: "final" }; break;
      case "error": yield { type: "error", content: String(data.content ?? "") }; break;
      default: break;
    }
  }
  write(buffer);
}
```

```ts
// apps/web/lib/agent-client-browser.ts
import { parseAgentBlocks, type AgentStreamEvent, type AgentCard } from "@/lib/agent-types";

export async function* streamAgent(
  body: { message?: string; profile_id?: string | null; locale?: string; card_action?: object },
  signal?: AbortSignal,
): AsyncGenerator<AgentStreamEvent> {
  const res = await fetch("/api/backend/agent/turn", {
    method: "POST",
    headers: { "Content-Type": "application/json", Accept: "text/event-stream" },
    body: JSON.stringify({ locale: "es", ...body }),
    signal,
  });
  if (!res.ok || !res.body) throw new Error(`streamAgent failed: ${res.status}`);
  const reader = res.body.getReader();
  const decoder = new TextDecoder();
  let buffer = "";
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, { stream: true });
    yield* parseAgentBlocks(() => buffer, (rest) => { buffer = rest; });
  }
  if (buffer.trim()) yield* parseAgentBlocks(() => buffer + "\n\n", (rest) => { buffer = rest; });
}

export async function getSuggestions(profileId: string | null, locale: string): Promise<AgentCard[]> {
  const qs = new URLSearchParams({ locale });

  const res = await fetch(`/api/backend/agent/suggestions?${qs.toString()}`, { cache: "no-store" });
  if (!res.ok) return [];
  const json = (await res.json()) as { cards: AgentCard[] };
  return json.cards ?? [];
}
```

```tsx
// apps/web/components/agent/agent-input.tsx
"use client";
import { useEffect, useRef, useState } from "react";
import { useTranslations } from "next-intl";
import { Mic, Send, Square } from "lucide-react";

type SpeechRecognitionLike = {
  lang: string; interimResults: boolean; continuous: boolean;
  start(): void; stop(): void;
  onresult: ((e: { results: { [i: number]: { [j: number]: { transcript: string } }; length: number } }) => void) | null;
  onend: (() => void) | null; onerror: (() => void) | null;
};
type SpeechCtor = new () => SpeechRecognitionLike;
function getSpeechCtor(): SpeechCtor | null {
  if (typeof window === "undefined") return null;
  const w = window as unknown as { SpeechRecognition?: SpeechCtor; webkitSpeechRecognition?: SpeechCtor };
  return w.SpeechRecognition ?? w.webkitSpeechRecognition ?? null;
}
const LANG: Record<string, string> = { es: "es-ES", en: "en-US", fr: "fr-FR" };

export function AgentInput({ onSubmit, onStop, disabled, locale }: {
  onSubmit: (text: string) => void; onStop: () => void; disabled: boolean; locale: string;
}) {
  const t = useTranslations("agent");
  const [input, setInput] = useState("");
  const [listening, setListening] = useState(false);
  const [micSupported, setMicSupported] = useState(false);
  const recRef = useRef<SpeechRecognitionLike | null>(null);
  const baseRef = useRef("");

  useEffect(() => { setMicSupported(getSpeechCtor() !== null); return () => recRef.current?.stop(); }, []);

  function toggleMic() {
    if (listening) { recRef.current?.stop(); return; }
    const Ctor = getSpeechCtor(); if (!Ctor) return;
    const rec = new Ctor();
    rec.lang = LANG[locale] ?? "es-ES"; rec.interimResults = true; rec.continuous = true;
    baseRef.current = input.trim() ? input + " " : "";
    rec.onresult = (e) => {
      let txt = ""; for (let i = 0; i < e.results.length; i++) txt += e.results[i][0].transcript;
      setInput(baseRef.current + txt);
    };
    rec.onend = () => setListening(false); rec.onerror = () => setListening(false);
    recRef.current = rec; setListening(true); rec.start();
  }

  function submit() { const text = input.trim(); if (!text) return; onSubmit(text); setInput(""); }

  return (
    <div className="flex items-end gap-2 border-t border-line bg-surface p-3">
      <textarea value={input} onChange={(e) => setInput(e.target.value)} rows={1}
        placeholder={t("placeholder")} aria-label={t("placeholder")}
        onKeyDown={(e) => { if (e.key === "Enter" && !e.shiftKey) { e.preventDefault(); submit(); } }}
        className="ad-card max-h-32 min-h-[44px] flex-1 resize-none px-3 py-2" />
      {micSupported && (
        <button type="button" onClick={toggleMic} aria-pressed={listening} aria-label={t("listen")}
          className={`ad-btn min-h-[44px] w-11 justify-center ${listening ? "ad-btn-accent" : "ad-btn-ghost"}`}>
          <Mic className="h-5 w-5" />
        </button>
      )}
      {disabled ? (
        <button type="button" onClick={onStop} aria-label={t("stop")} className="ad-btn ad-btn-ghost min-h-[44px] w-11 justify-center">
          <Square className="h-5 w-5" />
        </button>
      ) : (
        <button type="button" onClick={submit} disabled={!input.trim()} aria-label={t("send")}
          className="ad-btn ad-btn-primary min-h-[44px] w-11 justify-center">
          <Send className="h-5 w-5" />
        </button>
      )}
    </div>
  );
}
```

```tsx
// apps/web/components/agent/agent-canvas.tsx
"use client";
import { useEffect, useRef, useState } from "react";
import { useTranslations } from "next-intl";
import { streamAgent, getSuggestions } from "@/lib/agent-client-browser";
import type { AgentCard } from "@/lib/agent-types";
import { CardRenderer, type CardActionHandler } from "./cards/card-renderer";
import { AgentInput } from "./agent-input";
import { ProfileSwitcher } from "./profile-switcher";
import { useActiveProfile } from "@/lib/profile-context";

type Msg = { role: "user" | "assistant"; content: string };

export function AgentCanvas({ locale }: { locale: string }) {
  const t = useTranslations("agent");
  const { activeId } = useActiveProfile();
  const [messages, setMessages] = useState<Msg[]>([]);
  const [cards, setCards] = useState<AgentCard[]>([]);
  const [busy, setBusy] = useState(false);
  const abortRef = useRef<AbortController | null>(null);
  const epochRef = useRef(0);

  useEffect(() => {
    let alive = true;
    getSuggestions(activeId, locale).then((c) => { if (alive) setCards(c); }).catch(() => {});
    return () => { alive = false; };
  }, [activeId, locale]);

  async function drive(body: { message?: string; card_action?: object }) {
    const epoch = ++epochRef.current;
    const stale = () => epochRef.current !== epoch;
    const controller = new AbortController();
    abortRef.current = controller;
    setBusy(true);
    if (body.message) setMessages((p) => [...p, { role: "user", content: body.message! }, { role: "assistant", content: "" }]);
    try {
      for await (const ev of streamAgent({ ...body, profile_id: activeId, locale }, controller.signal)) {
        if (stale()) break;
        if (ev.type === "token") {
          setMessages((p) => { const n = [...p]; const last = n[n.length - 1];
            if (last?.role === "assistant") n[n.length - 1] = { ...last, content: last.content + ev.content }; return n; });
        } else if (ev.type === "card") {
          setCards((p) => [ev.card, ...p]);
        } else if (ev.type === "error") {
          setMessages((p) => { const n = [...p]; const last = n[n.length - 1];
            if (last?.role === "assistant") n[n.length - 1] = { ...last, content: t("errorAnswer") }; return n; });
        }
      }
    } catch { /* aborted */ } finally { if (!stale()) setBusy(false); }
  }

  const onCardAction: CardActionHandler = (intent, card, value) => {
    if (intent === "cancel") { setCards((p) => p.filter((c) => c.id !== card.id)); return; }
    if (intent === "confirm") {
      const pl = card.payload as { tool_name: string; tool_args: object };
      setCards((p) => p.filter((c) => c.id !== card.id));
      void drive({ card_action: { intent: "confirm", tool_name: pl.tool_name, tool_args: pl.tool_args } });
      return;
    }
    if (intent === "answer") {
      const pl = card.payload as { field: string };
      setCards((p) => p.filter((c) => c.id !== card.id));
      void drive({ card_action: { intent: "confirm", tool_name: "completar_perfil", tool_args: { field: pl.field, value } } });
      return;
    }
    // action intents (process_docs, open_briefing, ...) → send as a natural-language message
    void drive({ message: `[${intent}]` });
  };

  const cardRail = (
    <div className="flex flex-col gap-3 overflow-y-auto p-3" aria-label={t("suggestionsTitle")}>
      {cards.map((c) => <CardRenderer key={c.id} card={c} onAction={onCardAction} />)}
    </div>
  );

  return (
    <div data-testid="agent-canvas" className="flex h-[calc(100dvh-3.5rem)] flex-col md:flex-row">
      {/* Chat column */}
      <section className="flex min-h-0 flex-1 flex-col">
        <ProfileSwitcher />
        <div className="min-h-0 flex-1 overflow-y-auto p-3">
          {messages.length === 0 && <p className="ad-rise font-display text-lg text-ink-soft">{t("greeting")}</p>}
          {messages.map((m, i) => (
            <div key={i} className={`my-2 ${m.role === "user" ? "text-right" : ""}`}>
              <span className={`inline-block rounded-lg px-3 py-2 ${m.role === "user" ? "bg-pine-100" : "bg-surface-2"}`}>
                {m.content || (busy && m.role === "assistant" ? t("thinking") : "")}
              </span>
            </div>
          ))}
          {/* Mobile: cards render inline in the thread */}
          <div className="mt-3 flex flex-col gap-3 md:hidden">
            {cards.map((c) => <CardRenderer key={c.id} card={c} onAction={onCardAction} />)}
          </div>
        </div>
        <AgentInput locale={locale} disabled={busy} onStop={() => abortRef.current?.abort()}
                    onSubmit={(text) => void drive({ message: text })} />
      </section>
      {/* Desktop: card rail beside the chat */}
      <aside className="hidden w-80 border-l border-line md:flex md:flex-col">{cardRail}</aside>
    </div>
  );
}
```
