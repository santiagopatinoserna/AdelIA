# HIPAA Right of Access Request (United States)

> **Disclaimer**: This template is informational, NOT legal advice. AdelIA is not a law firm. Adapt to your case and, if your request is denied, consult the [HHS OCR Health Information Privacy](https://www.hhs.gov/hipaa/) or a healthcare attorney.

## How to use

1. Replace `<PLACEHOLDERS>` with your information
2. Send via **USPS Certified Mail with Return Receipt** (cost: ~$5) or via the provider's patient portal if available
3. Keep a signed copy and proof of delivery
4. Provider has **30 days** to respond (extensible by 30 more days with written notice)
5. If denied or no response → complaint to HHS OCR ([hhs.gov/hipaa/filing-a-complaint](https://www.hhs.gov/hipaa/filing-a-complaint/))

## Practical tips

- **USPS Certified Mail with Return Receipt** (~$5) provides legal proof of delivery and date. Highly recommended over plain mail.
- **Patient Portals** (MyChart, FollowMyHealth, etc.) often have a built-in request mechanism — use that if available, it's faster.
- **Cost**: First request is generally **free** for electronic records. Paper copies may incur "reasonable, cost-based" fees (HIPAA 164.524(c)(4)) — typically $0.10-0.50 per page.
- **State Law**: Some states (e.g., California Civil Code § 56.10) provide additional rights beyond HIPAA. Check your state.
- **Mental Health Records**: HIPAA-covered the same as other PHI. Psychotherapy session notes are excluded only if maintained separately from the main record.
- **Minors' Records**: Generally accessible by parent/guardian. Some states limit access for adolescent care (mental health, reproductive). Check state law.

## If denied or no response

1. **File a Complaint with HHS OCR**: [hhs.gov/hipaa/filing-a-complaint](https://www.hhs.gov/hipaa/filing-a-complaint/) — online form, takes ~15 minutes.
2. **Timeline for OCR**: 6-12 months typical investigation.
3. **Potential Penalties**: Up to $50,000 per violation (with annual cap of $1.5M per violation type) under HIPAA Enforcement Rule (45 CFR Part 160).
4. **State Attorney General**: Some states permit private right of action under state privacy laws.
